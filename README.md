# ⚡ gitscout

> **Hiring recon for github profiles** - Know who you're hiring before the interview.

---

## 📌 Project Overview

**GitScout** is a developer reconnaissance tool designed to evaluate GitHub profiles instantly. Instead of digging through endless repository tabs, GitScout aggregates public telemetry to deliver an actionable scouting report: key activity stats, high-impact repositories, language distribution, and an objective developer score-all wrapped in a terminal-inspired dark UI.

---

## ✨ Key Features

* **scout:** Pull core profile metadata—bio, total followers, tenure on GitHub, and repository count.
* **rank:** Automatically surface a candidate's best-performing repositories sorted by stars and forks.
* **score:** Calculate a transparent **0–100 Hire Score** based on account tenure, star count, forks, and network reach.
* **top languages:** Analyze and display the developer's primary programming language footprint.

---

## 🛠️ Tech Stack

* **Frontend:** React + Vite
* **Styling:** CSS / Dark Terminal Grid Theme
* **API:** GitHub REST API

## 🚀 Quick Start

### Prerequisites
Ensure you have **Node.js** installed on your system.

### Running Locally

1. Clone the repository:
   \\\Bash
   git clone https://github.com/Aditya-bakaa/Git-Scout.git
   cd Git-Scout
   \\\

2. Install dependencies:
   \\\Bash
   npm install
   \\\

3. Launch the local server:
   \\\Bash
   npm run dev
   \\\
